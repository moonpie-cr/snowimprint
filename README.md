# ❄️ 雪林小屋 · 雪地印记

> 林间的空地，留给你写字。

一个可以在浏览器里直接玩的 **3D 冬日互动网页**：在月光下的雪地上写字、踩脚印、躺下印雪天使、堆雪人、拍宝丽来；冷了就推门走进林中小屋，烤火、喝热可可、撸猫。

整个项目只有 **一个 HTML 文件**，不需要构建，也没有后端，打开就能用。

🔗 **在线体验**：`https://<你的 GitHub 用户名>.github.io/<仓库名>/`

## ✨ 功能一览

### 🌨️ 雪地
| 功能 | 说明 |
|---|---|
| ✍️ 写字 | 按住拖动，在雪地上写字。笔画是真正压进雪里的凹槽，边上的雪会鼓起来，月光会照出阴影；有细、中、粗三种笔刷 |
| 👣 脚印 | 拖动时左右脚交替留下靴印，方向跟着你走的路线转 |
| 🛌 躺进雪地 | 一个小人倒进雪里挥动手臂和双腿，起身后留下一个雪天使 |
| ⛄ 堆雪人 | 点 4 下：雪球滚过来越滚越大 → 放上身体 → 按上脑袋 → 戴上胡萝卜鼻子、树枝手、礼帽和围巾 |
| 🔤 文字印章 | 输入一句话，选字体，预览拖到想要的位置，再旋转方向后印下 |
| 🗺️ 平铺写字 | 镜头切到正上方俯视雪地，写出来的字不会变形（快捷键 `V`） |
| 🧭 环顾 | 360° 旋转视角，滚轮或双指缩放 |
| 🌨️ 落雪覆盖 | 新雪会慢慢把字迹盖住，可以随时暂停 |
| 🧹 清雪 | 下一场大雪，雪地恢复干净 |

### 🏠 林中小屋
- **体温系统**：在雪地里待久了体温会下降，屏幕四周会结出冰花，冷到一定程度画面还会发抖。
- **进屋**：点小屋或「进屋取暖」按钮，镜头飞到门前，门打开后进入屋内。
- **屋里的互动**：

| 互动 | 效果 |
|---|---|
| 🪵 添柴 | 火苗蹿高、火星飞溅 |
| ☕ 热可可 | 端起杯子喝一口，喝完可以续杯 |
| 🐱 撸猫 | 小猫抬头、摇尾巴、冒爱心、打呼噜 |

- 屋里拍的宝丽来会自动出现在壁炉上方的相框里。

### 📷 其他
- **宝丽来**：一键拍下当前画面，配上诗意的文字和日期，点照片可以下载 PNG。
- **声音**：风雪声、铃铛声、踩雪声、柴火噼啪声和猫叫，全部用 Web Audio 实时合成，不需要音频文件。
- **手机适配**：可以用手指写字，并且自动降低画面精度和粒子数量，保证流畅。

## 🚀 部署到 GitHub Pages

### 1. 准备文件
把 `snow-imprint-3d.html` 重命名为 **`index.html`**，这样访问仓库地址时会直接打开这个页面。

```
your-repo/
├── index.html        # 主页面（原 snow-imprint-3d.html）
├── README.md
└── screenshots/      # 可选，存放预览截图
```

### 2. 推送到 GitHub
```bash
git init
git add .
git commit -m "❄️ 雪林小屋 · 雪地印记"
git branch -M main
git remote add origin https://github.com/<你的用户名>/<仓库名>.git
git push -u origin main
```

### 3. 开启 Pages
1. 打开仓库的 **Settings → Pages**
2. **Source** 选 `Deploy from a branch`
3. **Branch** 选 `main`，目录选 `/ (root)`，点 **Save**
4. 等 1～2 分钟，页面顶部会显示访问地址：
   `https://<你的用户名>.github.io/<仓库名>/`

> 💡 如果仓库名就是 `<你的用户名>.github.io`，访问地址会是根域名 `https://<你的用户名>.github.io/`。

## 💻 本地运行

**方式 1：直接打开**
双击 `index.html`，用 Chrome、Edge、Safari 或 Firefox 打开即可。

**方式 2：本地服务器（推荐）**
有些浏览器对 `file://` 协议下的 ES Module 有限制，起一个本地服务器更稳妥：

```bash
# Python
python3 -m http.server 8080

# 或 Node.js
npx serve .
```

然后访问 `http://localhost:8080`。

## 🛠️ 技术实现

- **3D 渲染**：[Three.js](https://threejs.org/) r160，通过 ES Module 和 `importmap` 从 jsDelivr CDN 引入。
- **雪地印痕**：用一张 Canvas 2D 画布记录雪地的高度，R 通道存压下去的凹痕，G 通道存被推开鼓起的雪边。通过 `onBeforeCompile` 改造 `MeshStandardMaterial`：顶点着色器按这张图做位移，片元着色器根据高度差算出法线，所以印痕在光照下有真实的明暗。
- **积雪覆盖**：每隔一会儿把整张图的高度统一减掉一点，痕迹就会慢慢被新雪抹平。
- **场景**：小屋、雪人、小人和屋内陈设都用 Three.js 基础几何体搭建；雪松林用 `InstancedMesh` 批量渲染；天空、极光和窗外的雪景是自定义着色器。
- **粒子**：雪花、扬雪、炊烟、火星和蒸汽都用 `Points` / `Sprite` 实现。
- **音效**：全部用 Web Audio API 实时合成，没有任何音频文件。
- **字体**：Google Fonts，加载失败时自动换成系统楷体。

## ⚠️ 注意事项

- **需要联网**：Three.js 和字体都从 CDN 加载，第一次打开需要联网。
- **国内访问**：Google Fonts 在国内可能加载不出来，这时文字印章会自动换成楷体。如果想更稳定，可以把字体文件下载到仓库里，改成本地引用。
- **浏览器要求**：需要支持 WebGL 2 和 ES Module，近两年的主流浏览器都可以。
- **声音**：浏览器要求用户先操作页面才能播放声音，所以需要手动点一下右上角的「声音」按钮。
